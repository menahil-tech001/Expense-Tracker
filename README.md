## Python Expense Tracker

## Description
The Expense Tracker is a Python application designed to manage and track daily expenses. It allows users to record expenses, organize them by category, and calculate total spending.

## Features
- Add new expenses
- View all recorded expenses
- Calculate total expenses
- Generate category-wise summaries
- Update existing expenses
- Delete expenses
- Menu-driven interface

## Technologies Used
- Python
- Functions
- Lists and Dictionaries
- Loops and Conditional Statements

## How to Run
1. Clone this repository.
2. Open the project in PyCharm.
3. Run the Python file.
4. Select options from the menu to manage expenses.
